# Tool Defaults

- `js-reverse_list_network_requests`: look at the first page of default results first, paginate only if needed
- `js-reverse_search_in_sources`: default to `excludeMinified=true`
- `js-reverse_get_script_source`: read only small excerpts; prefer `js-reverse_save_script_source` for full sources
- `js-reverse_break_on_xhr`: only fill in URL fragments that hit reliably
- `js-reverse_get_paused_info`: check `frameIndex=0` first by default
