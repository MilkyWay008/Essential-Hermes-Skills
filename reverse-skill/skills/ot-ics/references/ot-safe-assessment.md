# OT Safe Assessment Checklist

1. Authorized scope and emergency contacts  
2. Whether active probing / write operations are allowed (default: no)  
3. Maintenance window and rollback plan  
4. Prefer traffic mirroring over port scanning  
5. On finding high-risk issues, stop expanding immediately and notify  
6. Report must distinguish: remotely exploitable vs requires physical access  

Common protocol ports (for identification, not exploitation): Modbus/TCP 502, S7comm 102, EtherNet/IP 44818, DNP3 20000.
